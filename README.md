# Friends Chat

Тёмный закрытый чат для друзей: только текст до 40 символов, одно сообщение в 5 секунд,
регистрация с одобрением администратора, бан, удаление сообщений и цветные теги, которые выдаёт только админ.

## Запуск

1. Создайте проект на supabase.com.
2. **SQL Editor** → вставьте и выполните весь `supabase/schema.sql`
   (если запускали старую версию — сначала сброс из комментария в начале файла).
3. **Authentication → Providers → Email**: для простого теста отключите **Confirm email**.
   Для публичного запуска оставьте включённым и настройте SMTP.
4. Зарегистрируйте свой аккаунт в приложении (заявка создастся со статусом `pending`).
5. В SQL Editor один раз выполните, подставив свой email:
   ```sql
   update public.profiles set role='admin', status='approved'
   where id=(select id from auth.users where email='ВАШ_EMAIL');
   ```
6. Скопируйте `.env.example` в `.env` и вставьте URL и anon key (Settings → API).
   `service_role` key в приложение вставлять нельзя.
7. `npm install`, затем `npm run dev`.
8. Публикация: `npm run build`, содержимое папки `dist` загрузите на хостинг
   (Netlify, Vercel, Cloudflare Pages и т.п.), не забыв задать те же две переменные окружения.

## Как это работает

- Новый аккаунт получает статус `pending`: читать и писать нельзя, пока админ не нажмёт «Одобрить».
  Страница ожидания обновляется сама.
- Админ-панель: войдите в свой админ-аккаунт и нажмите «Админ-панель» (адрес `/#admin`).
  Новые заявки появляются в ней сами. Только админ может: одобрять, банить, удалять любые сообщения,
  выдавать теги и цвета. Это защищено в базе данных, а не только скрыто в интерфейсе.
- Лимит 40 символов и пауза 5 секунд проверяются SQL-функцией `send_message` на сервере.
- Название чата «Наш чат» меняется поиском по этой строке в `src/App.tsx` и `index.html`.
